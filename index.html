Download
API: MuAPI /youtube-download

2
Transcribe
API: MuAPI /openai-whisper

3
Highlight Ranking
LLM virality framework: hook, emotional peak, opinion bomb, revelation, conflict, quotable

        
4
Dedupe + Smart Crop

🚀 Deploy ke Netlify — 1 Klik dari GitHub

      

        

          
Opsi A — Deploy via GitHub (Recommended)

          
    
            
  1. Push folder ini ke repo GitHub baru (atau fork Anil-matcha/AI-Youtube-Shorts-Generator lalu merge file ini).
    2. 
            
  2. Buka app.netlify.com/start → Import from Git.
    3. 
            
  3. Build command: (kosongkan) — Publish directory: . — Functions: netlify/functions
    4. 
            
  4. Set Environment Variables di Netlify Dashboard:
              
    MUAPI_API_KEY=xxx         # wajib untuk mode API
OPENAI_API_KEY=xxx        # untuk mode Local + OpenAI
GEMINI_API_KEY=xxx        # untuk mode Local + Gemini
LLM_PROVIDER=openai
    
            
    5. 
            
  5. Deploy! Akses di https://<site>.netlify.app
    6. 
          

          Deploy to Netlify ↗
        

        

          
Opsi B — Drag & Drop (tanpa Git)

          
    
            
  1. Jalankan npm run build atau zip folder ini.
    2. 
            
  2. Buka app.netlify.com/drop → drag zip.
    3. 
            
  3. Set env vars sama seperti Opsi A.
    4. 
          

          
Opsi C — Netlify CLI

          
npm i -g netlify-cli

netlify env:set MUAPI_API_KEY xxx
netlify deploy --prod

        

      

    

  


  
  

    

      
🔌 API — Netlify Functions

      

        

          
POST /.netlify/functions/generate

          
{
  "url": "https://youtube.com/watch?v=...",
  "num_clips": 3,
  "aspect_ratio": "9:16",
  "format": "720",
  "language": "auto",
  "mode": "api"
}

          
Response: { source_video_url, transcript, highlights, shorts[] } — sama dengan result.json CLI + --output-json

        

        

          
GET /.netlify/functions/health

          
{ "ok": true, "hasMuapi": true, "version": "2.0" }

          
cURL Example

          
curl -X POST https://<site>.netlify.app/.netlify/functions/generate \
  -H "Content-Type: application/json" \
  -d '{"url":"https://youtube.com/watch?v=...","num_clips":3}'
