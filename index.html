⚡ Kenapa Ganti ke AutoClip?

      

        
🔒
Local-First, No Upload
Tidak ada akun, tidak upload ke server orang. Pakai Ollama = 100% offline. BYO key (Anthropic/OpenAI/Gemini) cuma kirim transcript text, bukan video.

        
🎯
Speaker-Tracked Reframe
Crop 9:16 ngikutin siapa yang ngomong. Shot detection dulu, frame per shot — tidak panning lewat cut.

        
💬
4 Caption Styles
bold_pop, karaoke_fill, clean_lower, boxed. Font bundled SIL OFL, burn pakai libass — tidak fetch runtime.

        
♻️
Resume & Export 3 Rasio
Setiap stage tulis ke `~/.autoclip/work/{job_id}/` — gagal di caption? Resume dari reframe. Export 9:16/1:1/4:5, h264 yuv420p + AAC -14 LUFS.

      

      

        

          
🆚 Beda dari Repo Lama

          
Repo lama pakai MuAPI (bayar, kredit, 402). AutoClip gratis selamanya, tidak ada top-up, tidak ada 402. Pilihan LLM: Ollama lokal (gratis) atau BYO key mana saja (OpenRouter/Groq/DeepSeek/LM Studio).

        

        

          
🧩 Highlight Lebih Akurat

          
Model balikin word indices bukan timestamp — anti salah hitung. Timing diambil dari word timings terukur. Prompt di backend/autoclip/prompts/highlight_v1.txt — paling high-leverage buat tuning.

        

        

          
📦 Non-Goals (jujur)

          
Tidak ada direct post ke TikTok/IG/YT (butuh approval), tidak ada cloud/telemetry, tidak ada timeline editor selain trim & edit caption. Tidak pernah bypass DRM.

        

      

    

  


  

    

      
📖 Tutorial — Jalankan AutoClip Lokal (Gratis)

      
2 cara — Docker (paling gampang) atau manual. Butuh Python 3.11/3.12 (bukan 3.13), ffmpeg full (libass+libx264), Node 20.

      

        

          
🐳 Opsi A — Docker (Recommended)

          
git clone https://github.com/artbyjazi/autoclip.git
cd autoclip
docker compose -f docker/compose.yaml up --build
# GPU: docker compose -f docker/compose.yaml --profile gpu up --build
# buka http://localhost:8000

          
ffmpeg, Python, font sudah pinned di image. Volume ./media buat drop file tanpa upload UI.

        

        

          
💻 Opsi B — Manual

          
git clone https://github.com/artbyjazi/autoclip.git
cd autoclip && uv venv --python 3.11 && uv pip install -e ".[dev]"
cd frontend && npm install && npm run build && cd ..
autoclip doctor   # cek ffmpeg, python, GPU
autoclip serve    # http://localhost:8000

          
macOS: brew install ffmpeg-full (bukan ffmpeg biasa). Windows: winget install Gyan.FFmpeg

        

      

      

        
1
Tambah Provider
Settings → Keys → paste key Anthropic/OpenAI/Gemini atau autoclip config set-secret anthropic. Atau lokal: ollama pull llama3.1:8b (7B cukup, frontier lebih bagus hook).

        
2
Ingest
Paste YouTube link atau drop file. Kalau YouTube bot-check → Settings → Ingest → cookies from browser (close browser dulu).

        
3
Clip & Export
autoclip clip <url|file> atau via UI: review → pilih style → export. CLI: autoclip jobs, autoclip providers, autoclip styles
